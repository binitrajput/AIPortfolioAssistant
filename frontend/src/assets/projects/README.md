# Project photos

Add one image per project here. Use these filenames so they are easy to match to the cards:

- `yukta-vihar.jpg`
- `vision-bridge.jpg`
- `ai-portfolio-assistant.jpg`
- `personal-portfolio.jpg`
- `autonomous-finance-clerk.jpg`

JPEG, PNG, and WebP are supported. If you use another format, keep the same base filename and change the extension. Once the images are here, they can replace the illustrated project card artwork.
